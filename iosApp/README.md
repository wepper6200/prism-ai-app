# Prism AI для iPhone и iPad

Первая версия iOS рассчитана на iOS 17 и новее, устройства arm64. Чат, понимание фото, поиск по PDF/TXT/MD/DOCX, диктовка и озвучка используют модели на устройстве. Модели скачиваются только по нажатию пользователя, с проверкой размера и SHA-256. История, память и черновики хранятся в Application Support/PrismAI; каталог исключён из резервного копирования iCloud. Удаление приложения удаляет эти данные и скачанные модели.

В каталоге iOS предлагаются Prism 1 Lite и Prism 1 Flash, PrismFile Reader и модели голоса. Начните с Lite; Flash с модулем фото требует больше памяти. iOS может завершить приложение при нехватке памяти. Скачивание и генерацию следует выполнять с открытым приложением. Команды, рисование, видео, музыка, MCP, Store и установка обновлений из приложения в первой версии iOS отсутствуют.

## Сборка на Mac

Нужны Xcode с iOS SDK, JDK 21, CMake, Ninja и Python 3.11+. Версии приложения и закреплённые бинарные зависимости берутся из gradle/libs.versions.toml. Скрипт сборки скачивает проверенные по SHA-256 зависимости для компиляции; установленное приложение этого не делает.

Из корня репозитория:

~~~sh
bash iosApp/build.sh iphonesimulator Debug
bash iosApp/build.sh iphoneos Release
~~~

Вторая команда создаёт build/PrismAI-unsigned.ipa. Для сборки через Xcode сначала выполните python3 iosApp/configure.py и swift iosApp/icon.swift "$PWD", затем откройте iosApp/PrismAI.xcodeproj. Общий Kotlin-фреймворк и его ресурсы собираются стандартным embedAndSignAppleFrameworkForXcode. Подпись в командном скрипте отключена; в Xcode для собственного устройства выберите свою команду Signing & Capabilities.

## Установка

Неподписанный IPA требуется подписать своим Apple ID, например через Sideloadly, либо собрать и установить из Xcode. Пароль вводится только в выбранном инструменте установки. Доступность установки и срок подписи зависят от вашей учётной записи Apple. Включите режим разработчика на устройстве, если iOS его запросит. Готовый неподписанный IPA сам по себе на iPhone не устанавливается.

## Проверка

Apple workflow собирает приложение для симулятора и устройства, запускает реальный GGUF через общий Kotlin-движок, проверяет потоковый ответ, повторное использование контекста и восстановление после отмены. Скриншоты и результат находятся в артефакте ios-simulator-smoke; пакет — PrismAI-iOS-unsigned. Отдельная проверка C API выполняется на Linux. Распаковщик голоса и DOCX проверяются на повреждённых данных, выходе из каталога и символьных ссылках.

На физическом iPhone дополнительно проверьте разрешения камеры и микрофона, смену аудиоустройства, загрузку больших моделей с паузой и голосовой разговор. Симулятор не подтверждает скорость, расход памяти и работу камеры реального устройства.

## Проверка из Windows через браузер

Артефакт PrismAI-iOS-Simulator содержит PrismAI-iOS-Simulator.zip со сборкой для симулятора arm64. Распакуйте внешний архив артефакта GitHub и загрузите внутренний ZIP в Appetize: https://docs.appetize.io/platform/app-management/uploading-apps/ios . Обычный IPA для этого сервиса не подходит. Это самостоятельная загрузка в сторонний сервис; приложение из CI туда автоматически не отправляется.

Доступность запуска больших локальных моделей в Appetize зависит от ограничений памяти, диска и времени сессии; совместимость Prism с этим сервисом отдельно не подтверждена. Такой запуск не измеряет производительность настоящего iPhone. Для проверки моделей на аппаратуре iOS используйте физический iPhone, в том числе удалённое реальное устройство, если выбранный сервис позволяет загрузку моделей. Тестовые данные при облачном запуске остаются на устройстве сервиса.
