# Prism AI

Офлайн-ассистент для Windows, Android и iOS: чат, изображения, документы и голос. Модели работают на устройстве. Сеть используется для явных загрузок и включённых пользователем интернет-инструментов.

- Windows и Android: desktopApp и androidApp.
- iPhone и iPad: [сборка и установка iOS](iosApp/README.md).
- Общая логика и интерфейс: shared, Kotlin Multiplatform и Compose Multiplatform.
- Две темы: Material 3 и Liquid Glass, светлый и тёмный режимы.

Релизы публикуются только по команде владельца проекта.
