# Windows Setup

Сборка приложения:

```powershell
./gradlew.bat -Pprism.vulkan=true -Pprism.imagegen=true :desktopApp:createDistributable
./desktopApp/installer/build.ps1
```

Результат: build/installer/PrismAI-<версия>-windows-x64-Setup.exe.
Для готовой папки приложения можно передать -AppDirectory и -OutputDirectory.
Версия приложения, версия компилятора установщика и его SHA-256 берутся из gradle/libs.versions.toml.
Компилятор скачивается с официального GitHub, проверяется по SHA-256 и Authenticode и распаковывается в build/tools в портативном режиме.

Setup устанавливает программу для текущего пользователя в %LOCALAPPDATA%\Programs\Prism AI без запроса прав администратора.
Есть выбор папки, ярлык в меню «Пуск», необязательный ярлык на рабочем столе и удаление через настройки Windows.
Идентификатор установки ai.prism.desktop постоянный: следующая версия обновляет ту же установку.
Интерфейс установщика — русский и английский. Автоматической загрузки приложения или моделей в Setup нет.

Чаты, изображения, модели и временные файлы приложения лежат отдельно — в %LOCALAPPDATA%\PrismAI или в выбранной папке моделей.
Setup не переносит и не удаляет эти данные; удаление программы сохраняет пользовательские данные.
Установщик пока не подписывается Authenticode. Постоянный сертификат Android не является подписью Windows.

CI собирает и сохраняет артефакт PrismAI-windows-setup; при отдельно разрешённом выпуске Setup добавляется в релиз.
ZIP продолжает выпускаться для существующего механизма обновления и Prism Store.

Проверено 15 ноября 2026: сборка Setup, тихая установка в изолированную папку build с отдельным AppId,
совпадение установленного JAR, повторная установка, удаление программы и записи деинсталлятора,
сохранение пользовательского файла, которого не было в установочном пакете. Рабочая установка Prism AI не затрагивалась.

# Подпись APK

Для распространения используется release APK из CI с постоянными секретами PRISM_KEYSTORE_*.
Локальный debug APK без этих переменных подписывается другим отладочным сертификатом и не заменяет установленную release-версию.
Не следует удалять приложение ради установки такого APK: вместе с приложением можно потерять локальные данные.

Публичный SHA-256 сертификата предыдущей проверенной release-сборки:
dfdc9855d399b31638701b036debcb50e465b2b54b0d3c25ef265685062cafeb.
Перед передачей APK проверять apksigner verify --print-certs и сравнивать сертификат.
Для отдельной подписанной Android-сборки: workflow Build, параметр android_only=true. Публикации релиза это не выполняет.

## Запуск после установки

На странице «Готово» по умолчанию отмечен запуск Prism AI. Setup открывает EXE через ShellExecute
от имени исходного пользователя и явно задаёт рабочую папку приложения. При тихой установке автозапуска нет.
Локальный журнал Setup сохраняется в TEMP для диагностики. Сеть и данные чатов в журнал не передаются.

Проверка: test-autolaunch.ps1 -AppDirectory <готовая папка PrismAI>. Тест устанавливает отдельный пакет с уникальным AppId
в build, запускает настоящий PrismAI.exe со встроенной Java и безопасным проверочным main-классом, проверяет
запись о запуске и рабочую папку, затем удаляет тестовую установку. История, настройки и модели пользователя не открываются.
Интерактивный флажок страницы завершения в этом автоматическом тесте пропускается.
Проверка автоматически выполняется в Windows CI после сборки Setup.
